# AI-Оператор

Одностраничный лендинг практического курса «AI-Оператор» — про то, как управлять нейросетью и контролировать код, не будучи программистом с нуля.

## Стек

Чистый `index.html` — HTML/CSS/JS без сборки и зависимостей.

## Запуск

Открой `index.html` в браузере, либо разверни через любой статический сервер:

```bash
npx serve .
```
